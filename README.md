# AFRIKA — Landing Page Inmersiva

**Afrika** es una propuesta de alfajor artesanal presentada a través de una experiencia web interactiva, visual e inmersiva, desarrollada como parte de una presentación de tesis.

El sitio funciona como una extensión digital de la identidad del producto y busca transmitir su concepto, propuesta de valor e identidad visual mediante una experiencia de navegación diferente a la de una página web tradicional.

## Objetivo del proyecto

Desarrollar una landing page que acompañe la presentación de Afrika, convirtiendo la comunicación del producto en una experiencia audiovisual y narrativa.

La propuesta busca captar la atención del público, generar interés y presentar el alfajor de una manera creativa, combinando diseño web, animaciones e interacción.

## Experiencia visual

La landing está diseñada con un enfoque cinematográfico, donde el scroll se convierte en el principal recurso narrativo.

Incluye:

- Animaciones vinculadas al desplazamiento.
- Efectos de parallax y profundidad.
- Transiciones entre secciones.
- Elementos visuales con posicionamiento sticky.
- Animaciones de textos e imágenes.
- Fondos dinámicos y efectos de superposición.
- Microinteracciones para mejorar la navegación.
- Diseño adaptable a dispositivos móviles y computadoras.

Cada sección presenta una composición visual propia, manteniendo una identidad gráfica coherente durante todo el recorrido.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido del sitio.
- **CSS3:** diseño visual, animaciones, transiciones y efectos.
- **JavaScript:** interactividad, control de escenas y comportamiento de las animaciones.
- **QR Code:** generación de un código QR para compartir el sitio.
- **Netlify:** publicación y alojamiento del sitio web.

El proyecto utiliza tecnologías nativas, sin frameworks, dependencias externas ni procesos de compilación.

## Publicación

El sitio puede publicarse directamente en Netlify mediante su modalidad de implementación manual, sin necesidad de configurar un servidor o proceso de compilación.
Actualmente esta publicado en la siguiente URL: https://afrika-tesis.netlify.app/

## Código QR

La landing incluye una sección denominada **Compartí Afrika**, que genera un código QR asociado a la dirección pública del sitio.

Una vez publicado, se puede descargar el código QR en formato PNG para incorporarlo al tríptico y permitir que cualquier persona acceda a la experiencia desde su dispositivo móvil.

## Accesibilidad y rendimiento

Se contemplan diferentes condiciones de navegación:

- Scroll nativo, compatible con mouse, teclado y pantallas táctiles.
- Adaptación a distintos tamaños de pantalla.
- Compatibilidad con la preferencia del sistema para reducir movimiento.
- Uso de recursos optimizados y fuentes alojadas localmente.
- Sin dependencias de servicios externos para las animaciones principales.
